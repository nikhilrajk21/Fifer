# Fifer — Assignment 3

Fifer is a new, independent coursework prototype for exploring an application-guided 5-4-3-2-1 grounding experience using fictional scenarios. It does not diagnose, claim therapeutic effectiveness, or imply human monitoring.

## Planned setup

- Frontend: Vue with JavaScript in `frontend/`.
- Backend: Python with FastAPI in `backend/`.
- Database: SQLite, to be created in a later approved implementation stage.
- Communication: Vue → FastAPI → Python/SQLite.
- Development: local localhost project.
- Part 3.1 design: Figma or Figma Make; evidence and exports belong in `docs/mockups/`.

The current workspace is the project root; do not create another Fifer directory. No Expedia Lite files are used.

## Current status

Documentation scaffold only. No application code, dependencies, database, or real crisis contact integration has been created. Setup and run commands will be documented when implementation is authorized and verified.
